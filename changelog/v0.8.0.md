## v0.8.0 — Persistent Governed Worker（M3 Runtime Governance）

Kingdom 从 one-shot 委派升级为**真正可安全治理长期 Worker Session**（v0.8.0 命题：Worker 拥有长期 DSH Session，Kingdom 能以 Task/Attempt 为单位取得并约束其每次执行权；旧 one-shot 继续 `LEGACY_COMPAT`）。

### New（Schema v4 —— M3-S2，Owner 三次 Review APPROVED）
- **四套独立 Core Ledger**：`session_territory_affinities`（Session↔Territory，不可改绑，retire 只能一次）/
  `execution_leases`（一 Session 一 active Lease、一 Lease = 一 Attempt）/
  `capability_decisions`（GRANTED⇔ENFORCED 双向 CHECK）/
  `dispatch_records`（Dispatch Intent = COMMIT POINT，先于 Runtime side effect）。
- **executions 重建**：增 `execution_contract`（LEGACY_COMPAT | GOVERNED_PERSISTENT）/ `lease_id` / `capability_decision_id`；旧行 backfill LEGACY_COMPAT，不伪造历史。
- **21 个硬编码 trigger**（transition matrix + INSERT 状态守卫 + 完整 immutability + DELETE 保护 + evidence 前置）+ 每连接 `PRAGMA foreign_keys=ON` 回读断言。
- **迁移纪律修复**：ensureSchemaV2/V3 各 gate/写自己的目标版本（杜绝「旧迁移直写 4 跳过 v4」陷阱）；v4 单事务可回滚；正式 DB 受 **Formal DB Migration Gate** 保护（默认不自动迁移已有库）。

### New（Runtime Governance 全链 —— M3-S3/S4/S5）
- **DSH Persistent Backend**（`src/adapter/`）：`AgentRegistry.create/resume`（同一 session_ref 恢复同一长期会话）、`followup` dispatch、事件链重建 terminal。
- **Capability Gate**（`src/capability/`）：`Effective = Grant ∩ Ceiling ∩ Runtime Enforceable Set`；preflight 无副作用 → plan 先持久 → materialize（`permissionPresets.set` / `setSandboxMode` / `setApprovalPolicy('never')` / `tools.guard+restrict`）→ typed evidence；**Runtime 无法 enforce → DENIED + zero execution**。
- **Dispatch / Reconciliation**（`src/dispatch/`）：TX-3..TX-5 全链（Intent→Receipt→Correlation→Terminal Evidence→Release）；Reconcile 两维（SESSION_GONE ≠ TERMINAL；UNKNOWN 禁超时自动 ABORT → RECOVERING）；**G12 Foreign Dispatch 检测**（外来消息 → UNTRUSTED_RECOVERING）。
- **新工具**：`kingdom_start_task_governed`（grant_json 权威授权；DENIED 零执行；REWORK 唤醒同一 Worker；Claim → REVIEW 链不变）。
- **GUI**：快照/详情新增 Runtime Governance 投影（Worker Session / Lease / Decision / Dispatch；DENIED 显示原因、RECOVERING 如实显示、session 脱敏）。
