# Kingdom 人物造型与动作

本轮根据 2026-09-08 用户授权，直接优化现有十二个人物 SVG。角色与状态文件名、页面映射、授权及业务逻辑保持不变。挂载代码仅补充页面时钟驱动的 CSS 相位。

## 设计依据

当前 GUI 显示尺寸：宰相 76×96px（窄屏 62×80px），主管 68×88px，执行者 56×74px。人物所在网格列同步留出空间，保持相邻任务文字可读。之前分别为 64×78px、56×72px、44×58px；原素材更早使用 136×112 横向画布，主体在竖向容器中被额外缩小，宰相与主管工作动画为 760ms 三帧硬切。

新画布 80×112，以约三头身、稍大的面部、稳定的足部、分层衣物和粗细一致的轮廓组成一套小尺寸人物。保留原作的紫、绿、蓝角色方向，统一暖肤色、旧金配饰及墨绿深轮廓。不依赖主题背景颜色，不添加光晕、粒子或状态装饰。

| 身份 | 轮廓与配饰 | 动作意图 |
| --- | --- | --- |
| 宰相 | 高冠、银须、贯通长袍、卷轴 | 看卷、提笔指示、回看全局 |
| 主管 | 低帽、短披肩、领章、审查板 | 托稳、落笔核对、抬头确认 |
| 执行者 | 护额、分片护甲、分腿站姿、工具 | 重心就位、抬臂检视、收回待续 |

## 动作规则

- 脚部固定，重心转移围绕足部发生；胸廓呼吸、头部、肩、肘、衣摆分组，避免仅移动整体。
- 八秒循环包含准备、动作、短暂停留与回收；胸廓呼吸为四秒子循环。衣物与帽饰轻微滞后，角色间使用不同呼吸相位。
- GUI 强调版采用明确的肢体轮廓变化：宰相肩部最高提臂 58°、执行者举工具 70°，主管在核对与抬臂确认间切换。工作转头达 20°，思考低头达 23°并带轻微下沉；工作身体前倾至 8°，待命加入观察和短暂抬手，休息保留缓慢点头。衣摆和帽饰跟随动作并稍后收稳，八秒周期、关节支点及静态休息姿势保持不变。
- 待命包含观察与眨眼；工作动作表达职责；思考降低视线并收臂；休息保留闭眼和静止休息姿态。
- 使用 SVG `transform-box: view-box` 与明确关节坐标，避免包围盒变化导致轴心漂移。仅使用 CSS transform，不引入运行时库。
- `prefers-reduced-motion: reduce` 停止所有动画，仍保留状态静态姿势与原有文字状态。不存在仅靠动画传递的业务含义。
- 实际页面每 2500ms 重建主管与执行者卡片，原动画会被截断。SVG 挂载时通过 `document.timeline.currentTime` 设置负动画延迟，让同一页面时钟继续驱动动作；没有时钟时回退为 0s 初始相位。此改动只写一个 CSS 自定义属性，不改节点选择、角色映射、轮询、提交或治理状态。Feature Flow 影响为 none：仅动画呈现时间改变，无业务控制流、状态或权限影响。

统一作者源为 `scripts/art/generate-characters.mjs`，生成现有十二个自包含 SVG。运行命令：`node scripts/art/generate-characters.mjs`。修改生成源后应重新生成，不逐文件漂移。

参考：[MDN transform-box](https://developer.mozilla.org/en-US/docs/Web/CSS/transform-box)、[MDN prefers-reduced-motion](https://developer.mozilla.org/en-US/docs/Web/CSS/@media/prefers-reduced-motion)。采用原生 CSS 的原因是当前产品已直接内嵌 SVG，关节动画及减少动态效果均无需新增依赖。
